# 🏛️ Memory Palace Builder

> **"Don't memorize notes. Explore them."**

A premium, single-file memory-training platform. Paste any study material — notes, a chapter summary, term lists — and it is transformed into an explorable **memory palace**: themed rooms, journey stations, bizarre multi-sensory scenes, story chains and mnemonics, all built on the techniques memory champions actually use.

Then it does something most study tools don't: **it trains you to stop needing it**, through a 6-stage Academy that gradually hands the imagery-building over to you.

## ✨ Run it

It's one file. No build, no server, no dependencies.

- **Open `index.html` in any browser.** That's it. Works offline forever.
- Or serve it from anywhere static (GitHub Pages, Netlify, a USB stick).

All data lives in your browser's localStorage — export/import backups from Settings.

## 🧠 What's inside

| Pillar | Features |
|---|---|
| **Encoding** | Imagination Engine (offline palace generation), 12 themed room sets + your own home, Method of Loci stations, multi-sensory scenes (sight/sound/smell/touch/emotion), peg system for numbers, first-letter mnemonics, story linking, chunked 7-loci rooms |
| **Training** | Mental walkthrough mode (encode + recall walks), spaced repetition (SM-2 style, exam-aware), Quiz Mix (spatial / cloze / order / free recall, interleaved), Rapid Review flash mode, confidence calibration |
| **Analytics** | Memory-strength per locus, 30-day retention forecast, accuracy by recall type, calibration gap, 10-week activity heatmap, XP / levels / streaks / 12 badges |
| **Coaching** | Rule-based adaptive Memory Coach, "🧠 why" chips linking every feature to its cognitive-science principle, a 29-entry technique codex |
| **Independence** | 6-stage Academy (loci foundations → vivid imagery → home journeys → pegs → co-creation → solo architect), assistance levels that fade as you level up, image scoring on the SEE formula |
| **Extras** | Visual timelines, concept constellation maps, room stories, JSON export/import, sound design, reduced-motion support |

## 🤖 Optional: Claude AI mode

The app is fully functional offline. Adding an Anthropic API key in **Settings** unlocks:

- **AI-crafted scenes** — Claude writes imagery that encodes each fact's *meaning*, not just its keyword (uses structured outputs for guaranteed-valid responses)
- **Conversational coach** — ask strategy questions grounded in your real stats

The key is stored only in your browser and sent only to `api.anthropic.com` (with the official browser-access header).

## 🔬 The psychology engine

Every interaction is an implementation of a named principle — retrieval practice, the testing effect, spacing, interleaving, dual coding, elaborative encoding, the Von Restorff effect, emotional tagging, curiosity loops, goal gradients, desirable difficulties, metacognition, self-explanation, confidence calibration, memory reconsolidation, generation effect, chunking, context-dependent memory and more. Tap any **🧠 chip** in the app to see the science behind what you're doing, how the app uses it, and how to apply it without the app.
